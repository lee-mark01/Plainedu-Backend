
# 1️⃣ 리그 시스템 전체 구조

Plain edu의 리그는 단일 경쟁 구조가 아니라,

**4개의 독립 랭킹 체계**로 구성된다.

리그는 두 개의 모드로 나뉜다.

---

## 리그 모드 구조

```
Plain edu 리그
│
├── 개인 모드
│     ├── 개인 랭킹
│     └── 개인 소속 랭킹
│
└── 팀 모드
      ├── 팀 랭킹
      └── 팀 소속 랭킹
```

총 4개의 랭킹이 존재한다.

---

# 2️⃣ 시즌 기반 운영 구조

- 시즌 길이: 3개월
- 연 4회 운영
- 시즌별 점수 완전 독립
- 시즌 종료 시 계좌 초기화
- 시즌 중 합류 가능
- 참여 가중치 일 단위 반영

---

## 2.1 참여 가중치 구조

### SeasonDays

```
SeasonDays = (SeasonEnd - SeasonStart) + 1
```

### ActiveDays

```
ActiveStart = max(JoinDate, SeasonStart)
ActiveEnd = min(LeaveDate or SeasonEnd, SeasonEnd)

ActiveDays = (ActiveEnd - ActiveStart) + 1
```

### ParticipationRatio

```
ParticipationRatio = ActiveDays / SeasonDays
```

- 소속 리그 집계에만 사용
- 개인/팀 랭킹 1차 정렬에는 미적용
- ActiveDays → 출석일

---

# 3️⃣ 리그 종류별 상세 정의

---

# 🔵 [A] 개인 모드

개인 모드는 **투자 결과 중심 리그**이다.

단위는 `%`를 사용한다.

---

## 3.1 개인 랭킹 (Individual Ranking)

### 목적

개인의 순수 투자 판단 능력 평가

---

### 점수 정의

```
PersonalReturn = (Vt - V0) / V0
PersonalScore = PersonalReturn × 100 (%)
```

- 단순 누적 수익률
- TWR 미사용
- 수수료(0.03%) 즉시 반영

---

### 정렬 기준

1. PersonalScore
2. ParticipationRatio
3. ActiveDays

---

### 계좌 0원 처리 (파산)

- PersonalScore = -100%
- 거래 불가
- 리그 참여 유지

---

## 3.2 개인 소속 랭킹 (Org Individual Ranking)

### 목적

학교/대학 단위 집단 성과 평가

---

### 계산 방식 (가중 평균)

```
OrgScore_individual =
Σ (PersonalScore × ParticipationRatio)
÷ Σ (ParticipationRatio)
```

- 단순 평균 아님
- 오래 참여한 구성원 비중 반영
- 분모 0 → 집계 제외

---

# 🔴 [B] 팀 모드

팀 모드는 **전략 기반 혼합 점수 리그**이다.

단위는 **Point**를 사용한다.

---

## 4️⃣ 팀 랭킹 (Team Ranking)

### 목적

전략 실행 능력 + 투자 성과 동시 평가

---

## 4.1 팀 점수 구조

```
TeamScore = (R% × 0.9) + (Alignment × 0.1)
```

- 단위: Point
- 소수점 1자리

---

## 4.2 R% (팀 수익률)

```
TeamReturn = (Vt - V0) / V0
R% = TeamReturn × 100
```

- 단위: %

---

## 4.3 Alignment (전략 준수 점수)

### 계산 기준

- 매주 금요일 정규장 종가
- Active MP 기준
- 비중은 0~100% 스케일 (옵션 B)

---

### 4.3.1 현재 비중

```
TotalValue = Σ(종가×수량) + Cash

CurrentWeight_i = (종가×수량)/TotalValue ×100
CurrentWeight_CASH = Cash/TotalValue ×100
```

---

### 4.3.2 목표 비중

- MP 정의 종목
- 현금 필수
- 합계 100% 강제
- 목표 외 종목 = 0%

---

### 4.3.3 허용 오차

```
Tolerance_i = TargetWeight_i × 0.02
RawDiff_i = |CurrentWeight_i - TargetWeight_i|
```

---

### 4.3.4 오차 계산

```
RawDiff_i ≤ Tolerance_i → Diff_i = 0
RawDiff_i > Tolerance_i → Diff_i = RawDiff_i - Tolerance_i
```

---

### 4.3.5 TotalDiff

```
TotalDiff = Σ Diff_i
```

---

### 4.3.6 Alignment 최종 산식

```
Alignment = 100 × (1 - TotalDiff / 200)
```

- 0~100 범위
- 클램프 적용

---

## 4.4 팀 소속 랭킹 (Org Team Ranking)

### 목적

학교/대학 단위 전략 실행 성과 평가

---

### 계산 방식

```
OrgScore_team =
Σ (TeamScore × ParticipationRatio)
÷ Σ (ParticipationRatio)
```

- 단위: Point

---

# 5️⃣ 리그 종류별 계산 로직 요약표 (한 장 정리)

|리그 종류|평가 대상|메인 단위|계산식|가중치 적용|
|---|---|---|---|---|
|개인 랭킹|개인|%|(Vt-V0)/V0 ×100|❌|
|개인 소속 랭킹|학교(개인 집합)|%|Σ(개인점수×참여율)/Σ참여율|✅ ParticipationRatio|
|팀 랭킹|팀|Point|(R%×0.9)+(Alignment×0.1)|❌|
|팀 소속 랭킹|학교(팀 집합)|Point|Σ(팀점수×참여율)/Σ참여율|✅ ParticipationRatio|

---

# 6️⃣ 리그 구조 철학 정리

## 개인 모드

- 순수 수익률 경쟁
- 실전 판단력 중심

## 팀 모드

- 전략 설계 + 실행 규율 중심
- 전략 일관성 점수 포함
- 수익률만으로 결정되지 않음

---

# 7️⃣ 전체 리그 시스템 요약 구조도

```
시즌
│
├── 개인 모드
│     ├── 개인 수익률 (%)
│     └── 소속 평균 수익률 (%)
│
└── 팀 모드
      ├── R% (성과)
      ├── Alignment (전략준수)
      ├── TeamScore (Point)
      └── 소속 평균 TeamScore (Point)
```

---

# 8️⃣ 최종 구조 핵심 요약

- 개인은 % 중심
- 팀은 Point 중심
- ParticipationRatio는 집단 평균에만 적용
- Alignment는 전략 훈련 핵심 장치
- TeamScore는 성과+전략 혼합 지표

|구분|개인 모드|팀 모드|

## 7️⃣ 단위 체계 시각 정리

% = 실제 투자 성과
Point = 전략 포함 평가 점수
